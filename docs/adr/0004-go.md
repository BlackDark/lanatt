# Go for the daemon

lanatt is a root host daemon with no UI. The stack default is TypeScript on Bun. The daemon is Go: one static binary, in the same language as the existing macvlan CNI plugins.

## Considered options

- TypeScript on Bun. Rejected: this process creates host interfaces. It should not carry a JavaScript runtime.
- Rust. Rejected for v1: nothing here embeds a native library, and there is no latency budget that Go misses.
